# WhatsApp Appointment Reminder System


The WhatsApp Appointment Reminder System is a full-stack web application that allows users to schedule customer appointments, store them in a database, and automatically send appointment confirmation and reminder messages through WhatsApp (or SMS if WhatsApp is unavailable).

This project demonstrates backend API development, database integration, messaging service integration, scheduling automation, and frontend development.


## Features

* Create appointments through a web form
* Store appointment data in MongoDB
* Send automatic WhatsApp confirmation messages
* Display all appointments in a live dashboard
* Automatic reminder messages sent 1 hour before appointments
* RESTful API architecture
* Error handling and validation
* Responsive and user-friendly interface
